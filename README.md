# Aziz Akbar Ashshiddiq — Portfolio

A recruiter-focused portfolio built with SvelteKit and Tailwind CSS. The site presents selected work, experience, and direct contact paths without theme switching or interaction-heavy effects.

## Commands

```bash
npm run dev
npm run build
npm run lint
npm test
```

## Content

Portfolio content lives in `src/lib/portfolioData.js`. Keep project descriptions factual: state the context, your role, and the technical focus without inventing metrics.
